# Ronin Treasury Balances

A Node.js application for pulling and managing Ronin Treasury Balances.

## Prerequisites

- Node.js 18+ 
- npm or yarn

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The application will start on `http://localhost:3000`

## Production Build

```bash
npm run build
npm start
```

## Testing

```bash
npm test
```

## Linting

```bash
npm run lint
```

## Project Structure

```
.
├── public/                 # Static files (HTML, CSS, JS)
├── index.js               # Main entry point
├── package.json           # Project dependencies
└── README.md             # Documentation
```

## Features

- Express.js server
- Static file serving
- RESTful API ready
- Development hot-reload with nodemon
